# Chaos Choice — Forge 1.7.10

> Ещё два мода в этом же репозитории, каждый своим `.jar`:
> **FastBuild** — палочка быстрого строительства ([README-fastbuild.md](README-fastbuild.md), папка `fastbuild/`);
> **Drill** — бур 3×3 ([README-drill.md](README-drill.md), папка `drill/`).

Мод для **Minecraft 1.7.10 + Forge**. Раз в минуту внизу экрана, прямо над
шкалой опыта, появляется отсчёт **60 секунд** и меню с двумя случайными
«хаосами»:

> A) Удалить всех куриц | B) Получить 1 алмаз — но вся вода вокруг исчезает

- Выбрал вариант — он **сразу** исполняется (кто первый нажал, тот и решил).
- Закрыл меню — оно вернётся само через ~8 секунд, пока идёт отсчёт.
- Не успел за 60 секунд — вариант выбирает судьба, и он тоже срабатывает.
- За 10 секунд до новой волны внизу тикает «Следующая волна: Nс».

Всего **71 вариант**: удаления мобов и предметов, и подарки с подвохом.
Набор подогнан под 1.7.10 — без незерита, элитр и трезубца.

## Сборка через GitHub Actions

`.jar` собирается в облаке, на телефоне ничего компилировать не надо.

### Способ 1 — с компьютера (5 минут)

1. Зарегистрируйся на **github.com**.
2. **+ → New repository**: имя `chaos-choice`, тип **Public**, без README →
   **Create repository**.
3. Распакуй `ChaosChoice-Forge-1.7.10.zip` и **перетащи в браузер всё
   содержимое папки** — вместе с папкой `src` и скрытой `.github`. Важно:
   `build.gradle` должен лежать в корне репозитория.
4. **Commit changes**.
5. Вкладка **Actions** → слева **Build ChaosChoice (1.7.10)** → справа
   **Run workflow** → **Run workflow**.
6. Первый раз 5–15 минут (ForgeGradle качает и декомпилирует Minecraft).
   Появилась зелёная галочка → зайди в неё → внизу **Artifacts** →
   скачай **ChaosChoice-1.7.10** (это zip, внутри `.jar`).

### Способ 2 — только с телефона

GitHub в мобильном браузере (лучше включить «Версия для ПК»):

1. Создай пустой публичный репозиторий, как выше.
2. **Add file → Upload files** и залей файлы: `build.gradle`,
   `settings.gradle`, `gradle.properties`, `README.md`.
3. Папку `src` заливай по одной: **Add file → Create new file**, в поле
   имени вставь полный путь, например
   `src/main/java/com/narezany/chaoschoice/ChoiceManager.java`, и вставь
   код файла. Так же для остальных `*.java` и `mcmod.info`.
4. Файл сборки: **Add file → Create new file**, имя
   `.github/workflows/build.yml`, содержимое скопируй из файла
   `GITHUB_WORKFLOW.yml` в корне (он там для удобства, сам по себе не
   нужен).
5. Дальше — вкладка **Actions**, как в способе 1.

Долго и муторно, но других путей без компьютера нет.

### Если что-то пошло не так

Пришли мне текст ошибки из **Actions** (упавший run → шаг **Build mod** →
последние строки). Правки внесу, пересоберём. Частые причины:

- `build.gradle` попал не в корень, а в подпапку — перенеси;
- файл workflow не в `.github/workflows/` — путь важен;
- репозиторий приватный — для Actions это не мешает, но сделай Public
  на всякий случай.

## Установка

1. Нужен **Forge 1.7.10** (любая сборка 10.13.x, лучше 10.13.4.1614).
2. Положи `.jar` в папку `.minecraft/mods`.
3. Запусти игру. Первый выбор — через 15 секунд после входа в мир.

Команды (работают и в одиночной игре):

- `/chaos start` — запустить волну прямо сейчас
- `/chaos stop` — выключить
- `/chaos info` — что сейчас происходит

## Настройки

Файл `config/ChaosChoice.cfg` появляется после первого запуска:

```
timing {
    firstWaveSeconds=15      # пауза до первой волны
    waveIntervalSeconds=60   # пауза после волны
    choiceSeconds=60         # сколько даётся на выбор
}
world {
    blockBudgetPerTick=1500  # сколько блоков менять за тик
}
```

Хочешь реже — поставь `waveIntervalSeconds=180`. Хочешь совсем без пауз —
`waveIntervalSeconds=1` (минимум 5 секунд по коду).

## Как это устроено

```
src/main/java/com/narezany/chaoschoice/
  ChaosChoice.java      — @Mod, регистрация тиков и команды
  ChoiceManager.java    — таймер волн, голосование, «судьба»
  ChaosRegistry.java    — список вариантов
  ChaosRunner.java      — исполнение действий (команды + правка мира)
  BlockJobs.java        — очередь правок блоков порциями
  ChaosConfig.java      — чтение конфига
  CommandChaos.java     — /chaos
  network/              — пакеты: голос, состояние волны, открытие меню
  client/               — HUD над шкалой опыта и меню выбора
```

Действия вроде `give`/`effect`/`summon`/`tp`/`weather`/`time` выполняются
через серверные команды — так мод не зависит от внутренних методов
Minecraft и собирается без сюрпризов.
