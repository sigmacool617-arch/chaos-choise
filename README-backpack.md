# Backpack — рюкзаки для Forge 1.7.10

Три рюкзака: 9, 18 и 27 слотов. Вещи лежат в самом предмете (NBT), поэтому
рюкзак можно перекладывать в сундук, выбрасывать и подбирать — содержимое
останется.

## Крафт

**1 уровень — кожаный, 9 слотов**

```
[кожа]  [кожа]  [кожа]
[нитка] [нитка] [нитка]
[кожа]  [кожа]  [кожа]
```

Вместо кожи подойдёт и кожаная туника — оба варианта прописаны
в моде, работает любой.

**2 уровень — железный, 18 слотов**

```
[железо] [железо]  [железо]
[железо] [рюкзак 1] [железо]
[железо] [железо]  [железо]
```

**3 уровень — алмазный, 27 слотов**

```
[алмаз] [кожа]   [железо]
[алмаз] [рюкзак 2] [железо]
[алмаз] [железо] [железо]
```

## Как пользоваться

- ПКМ рюкзаком в руке — открывается окно.
- Shift+ПКМ ничего не открывает (чтобы можно было спокойно ставить блоки).
- Рюкзак в рюкзак положить нельзя — чтобы не было бесконечных карманов.
- Shift+клик по предмету перекладывает его между рюкзаком и инвентарём.
- Содержимое пишется в NBT предмета при каждом изменении, поэтому
  переживает выход из мира (в 1.0.0 вещи терялись из-за того, что
  ванильный сервер заменяет предмет в руке копией после правого клика).

Код: `backpack/src/main/java/com/narezany/backpack/`

- `ItemBackpack.java` — предмет и уровень;
- `InventoryBackpack.java` — содержимое в NBT предмета;
- `ContainerBackpack.java` — окно и слоты;
- `GuiBackpack.java` — отрисовка окна (без текстур: панель и рамки);
- `CommonProxy.java` / `ClientProxy.java` — серверная и клиентская части.

Мод нужен и клиенту, и серверу.
