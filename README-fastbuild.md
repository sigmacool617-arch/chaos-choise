# Моды для Forge 1.7.10

Два независимых мода, каждый собирается своим `.jar`:

| Папка | Мод | Что делает |
|---|---|---|
| корень | **Chaos Choice** | раз в минуту два случайных «хаоса» на выбор |
| `fastbuild/` | **FastBuild** | палочка быстрого строительства (мини-WorldEdit) |

## Сборка

`.github/workflows/build.yml` собирает оба: сначала корневой проект, потом
`fastbuild`. В Actions появятся два артефакта — **ChaosChoice-1.7.10** и
**FastBuild-1.7.10**.

Локально (если есть ПК с Java 8 и Gradle 7):

```bash
gradle build
gradle -p fastbuild build
```

## FastBuild — палочка быстрого строительства

**Крафт** (4 железа + 2 палки, по схеме):

```
[железо]   [ ]   [железо]
[железо] [палка] [железо]
   [ ]   [палка]   [ ]
```

**Как пользоваться:**

1. Возьми палочку в руку.
2. **ЛКМ** по блоку — в чате «Точка 1: x y z». Блок при этом **не ломается**.
3. **ЛКМ** по другому блоку — «Точка 2», сразу показывает объём в блоках.
4. **ПКМ** по любому блоку — область между точками заполняется **материалом
   этого блока** (с его вариантом: дуб/берёза, цвет шерсти и т.п.).
5. **Shift+ПКМ** — сбросить выделение.

Ограничения и детали:

- максимум **32 768 блоков** за раз (32×32×32), иначе в чат придёт отказ;
- заполнение идёт порциями по 1200 блоков за тик — 32 тысячи встанут примерно
  за 1.5 секунды, игра не подвиснет;
- блоки **тратятся** из инвентаря: на заливку нужно столько же предметов, сколько
  блоков встанет, иначе в чат придёт «не хватает: нужно X, в инвентаре Y»;
- в креативе материал не списывается (как и должно быть);
- точки запоминаются по игроку и по измерению: в другой мир с ними не пойдёшь;
- работает и в одиночной игре, и на сервере (мод нужен и клиенту, и серверу).

Код: `fastbuild/src/main/java/com/narezany/fastbuild/`

- `FastBuild.java` — регистрация предмета, крафта, обработчиков;
- `ItemBuilderStick.java` — предмет и правый клик;
- `LeftClickHandler.java` — левый клик (отменяет ломание блока);
- `SelectionStore.java` — точки и проверки;
- `FillJobs.java` — порционное заполнение;
- `network/` — пакет с координатами клика.
